SEO kỹ thuật

CẦN CẢI THIỆN6.0

Nền tốt: meta, Open Graph, Schema MedicalBusiness. Thiếu sitemap.xml, robots.txt, thẻ canonical, tối ưu local SEO (đồng bộ NAP với Google Business).

Tốc độ & Core Web Vitals

CẦN CẢI THIỆN6.0

Web tĩnh + ảnh webp + lazy-load = nền tốt, nhưng chưa đo thật (PageSpeed), font Google chặn render, ảnh chưa responsive srcset, chưa CDN. Chuẩn top: LCP < 2.5s, CLS < 0.1, điểm > 90.

Lộ trình nâng điểm 5.7 → 8.5+

Sửa theo đúng thứ tự "kéo điểm" nhanh nhất

  1. Nối form đặt lịch về Zalo/Google Sheet + nhúng chat Zalo OA → Chuyển đổi 5.0 ⭢ 8.5 (em làm được ngay)
  2. Trang Chính sách + Điều khoản + cookie → Pháp lý 3.0 ⭢ 8.0 (em làm được ngay)
  3. Gắn GA4 + Search Console + Pixel → Đo lường 1.5 ⭢ 8.0 (cần anh tạo/đưa mã)
  4. Khối review Google thật (sao + số lượt) + 1–2 video testimonial → Bằng chứng 5.0 ⭢ 8.5
  5. Chứng chỉ hành nghề + ảnh bằng cấp + tiểu sử bác sĩ → Uy tín 5.5 ⭢ 8.5
  6. Blog kiến thức da (2 bài/tuần từ 55 script) → EEAT 3.5 ⭢ 7.5 (dài hạn)

Chỉ cần xong 4 việc đầu, điểm tổng dự kiến lên ~7.6/10 — đủ tự tin bật quảng cáo. Xong cả 6, web vào nhóm 8.5+ đẳng cấp khu vực.
