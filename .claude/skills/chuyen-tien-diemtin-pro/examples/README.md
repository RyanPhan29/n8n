# Ví dụ thật (trong `video-factory/remotion-demo/src/ShortSpecs.tsx`)

Mở các spec này để copy pattern:

| Dạng | Spec (slug) | Học được gì |
|---|---|---|
| **Điểm tin + đọc vị + BIỂU ĐỒ** | `SHORT_PNJ` (ShortPNJ) | `ah:false` cảnh biểu đồ + ghép chart (`overlay_chart.sh`) + giọng châm biếm + trung lập |
| **Điểm tin + 2 beat đọc vị** | `SHORT_LONGTHANH936` | thẻ bằng chứng + `👁 Anh Hai đọc vị` + nghịch lý + trung lập (dẫn Thanh tra) |
| **Bóc bẫy tiêu dùng** | `SHORT_KIMCUONG_GIA` | hook "chưa chắc" → rủi ro → giải pháp → hỏi |
| **Xung đột kéo comment** | `SHORT_LIENNH` | so sánh gây tức (2,2% vs 12–14%) → bẻ kèo → câu hỏi công bằng |
| **Bóc comment (Phần 2)** | `SHORT_THUEDAT_P2` | card comment giả lập + phân biệt 2 phe |
| **Thẻ bằng chứng PRO gốc** | `SHORT_KIMCUONG`, `SHORT_DIEMTIN` | `source` + `evidence` + `evidenceTop` |

Biểu đồ mẫu: `video-factory/tools/pnj_chart.py` (đổi mảng số → chạy `python3 pnj_chart.py`).
